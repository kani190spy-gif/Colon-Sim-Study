# Colony Sim (study-powered vault)

A single-page HTML Canvas colony game fueled by studying (Anki, UWorld, CMS forms).
Live build is published as a claude.ai artifact; saves sync to the player's Claude account.

- `src/index.html` — the game (single file, published as-is)
- `tests/` — Playwright regression scripts (run against a wrapped copy of the page)
